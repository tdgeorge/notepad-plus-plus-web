# Web app (`web/`)

This directory contains the Next.js application for glitch.txt.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
npm run start
```

## Highlights

- Next.js App Router application
- In-browser text editing experience inspired by Notepad++
- Syntax highlighting and theme support

## PdfCraft tab

**File → Open PdfCraft Tab** opens the [PdfCraft](https://github.com/storytold/pdfcraft) PDF workbench (its WebAssembly build, vendored in `public/pdfcraft/`) in an editor tab.
